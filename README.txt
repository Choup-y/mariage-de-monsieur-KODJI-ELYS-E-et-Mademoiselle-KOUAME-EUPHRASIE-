SITE D'INVITATION DE MARIAGE — ÉLYSÉE & EUPHRASIE
===================================================

CONTENU
- index.html : site complet (HTML, CSS et JavaScript dans un seul fichier)
- photos/ : placez ici les cinq photos du mariage.

AVANT LA PUBLICATION
1. Ouvrez https://formspree.io/ et créez un compte.
2. Créez un nouveau formulaire (New Form) et copiez son identifiant, par exemple xabcdefg.
3. Dans index.html, cherchez :
   https://formspree.io/f/mnppjjjj
   Remplacez mnppjjjj par votre identifiant réel.
   Exemple : https://formspree.io/f/xabcdefg
4. Enregistrez index.html.
5. Photos : nommez les fichiers photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg et photo5.jpg et mettez-les dans le dossier photos/.
   - photo1.jpg = grande photo d'accueil
   - photo2.jpg à photo5.jpg = galerie
   Si vos photos sont en PNG ou WEBP, adaptez les extensions dans index.html.

LIEUX
Le site présente actuellement la Mairie de Cocody comme lieu de cérémonie et The Rezy Event & Lounge comme lieu de réception, d'après les informations disponibles. Vérifiez les horaires et adresses avant publication.

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Connectez-vous à https://github.com/ ou créez un compte.
2. Cliquez sur New repository. Nom suggéré : mariage-elysee-euphrasie
3. Choisissez Public, puis Create repository.
4. Dans le dépôt, utilisez Add file > Upload files et importez index.html et le dossier photos/ avec ses images.
5. Cliquez sur Commit changes.
6. Ouvrez Settings > Pages.
7. Sous Build and deployment, choisissez Deploy from a branch.
8. Sélectionnez la branche main et le dossier /(root), puis Save.
9. Attendez quelques minutes. GitHub affichera l'adresse publique du site dans Settings > Pages.

TESTS AVANT DE PARTAGER
- Ouvrez le site sur un téléphone.
- Envoyez une réponse de test RSVP et vérifiez qu'elle arrive dans Formspree.
- Vérifiez les photos, les lieux, le compte à rebours et la date limite RSVP.
- Ne partagez pas le lien final tant que le formulaire n'a pas été testé.

PERSONNALISATION
Le texte est en français. Vous pouvez modifier directement les noms, dates, lieux, horaires, couleurs et messages dans index.html.
